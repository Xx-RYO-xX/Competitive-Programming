## bisect モジュール
### コード
```python
import bisect              
bisect.bisect_left(a, x)   # aのリストに対して値xを二分探索して、左側の挿入点を返す
bisect.bisect_right(a, x)  # aのリストに対して値xを二分探索して、右側の挿入点を返す

## 以下、https://docs.python.org/ja/3/library/bisect.html#searching-sorted-lists から引用
def index(a, x):
    'xにちょうど等しい左端の値を見つける'
    i = bisect_left(a, x)
    if i != len(a) and a[i] == x:
        return i
    raise ValueError

def find_lt(a, x):
    'xより小さい右端の値を見つける'
    i = bisect_left(a, x)
    if i:
        return a[i-1]
    raise ValueError

def find_le(a, x):
    'x以下の右端の値を見つける'
    i = bisect_right(a, x)
    if i:
        return a[i-1]
    raise ValueError

def find_gt(a, x):
    'xより大きい左端の値を見つける'
    i = bisect_right(a, x)
    if i != len(a):
        return a[i]
    raise ValueError

def find_ge(a, x):
    '左端の項目がx以上であることを確認する'
    i = bisect_left(a, x)
    if i != len(a):
        return a[i]
    raise ValueError
```
## めぐる式二分探索
### コード
```python
    '''
    初期値のng,okを受け取り,is_okを満たす最小(最大)のokを返す
    まずis_okを定義すべし
    ng ok は  とり得る最小の値-1 とり得る最大の値+1
    最大最小が逆の場合はよしなにひっくり返す
    '''
    while (abs(ok - ng) > 1):
        mid = (ok + ng) // 2
        if is_ok(mid):
            ok = mid
        else:
            ng = mid
    return ok
```
#### 解説
めぐる式二分探索は、答えの候補 `x` に対する判定 `is_ok(x)` が、ある境界を境に
`False` から `True`（または `True` から `False`）へ一度だけ変化するときに、その境界を探す方法です。

上のコードでは、探索中は常に次の状態を保ちます。

- `ok`：`is_ok(ok) == True` となる値（または、`True` とみなす番兵）
- `ng`：`is_ok(ng) == False` となる値（または、`False` とみなす番兵）

`ok` と `ng` の中間値 `mid` を調べ、条件を満たせば `ok = mid`、満たさなければ
`ng = mid` とします。これを繰り返すと `ok` と `ng` の間隔が半分ずつ狭まり、
`abs(ok - ng) == 1` になった時点で、`ok` が条件を満たす境界の値になります。

例えば、「`x` 以上となる配列要素のうち最小のもの」を探す場合は、次のように書けます。

```python
a = [1, 3, 5, 8, 10]
x = 6

def is_ok(i):
    return a[i] >= x

ng = -1       # False とみなす番兵
ok = len(a)   # True とみなす番兵（該当する要素がない場合の戻り値にもなる）

while abs(ok - ng) > 1:
    mid = (ok + ng) // 2
    if is_ok(mid):
        ok = mid
    else:
        ng = mid

# ok == 3（a[3] == 8）
```

初期値には「条件を満たすことが分かっている値」と「満たさないことが分かっている値」を置きます。
そのような値が探索範囲内にない場合は、範囲外の値を仮想的な番兵として使えます。ただし上の例の
`ok = len(a)` のような番兵は、`is_ok` に渡して評価しないようにします。最大値を求めたい場合は、
`ok` と `ng` の位置関係や判定条件を反転させます。

探索範囲の大きさを $N$ とすると、計算量は $O(\log N)$ です。
